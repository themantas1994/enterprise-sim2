# Enterprise Engineering Simulator 2

A cross-platform (Windows, Linux, Android) engineering-station simulator for the USS Enterprise NCC-1701-D
(Galaxy class), with LCARS panels and a systems model based on *Star Trek: The Next Generation Technical
Manual* (Sternbach and Okuda, 1991), the project's single source of truth.

> **Fan-made, not affiliated with Paramount/CBS.** Star Trek and all related names, ships and designs are
> trademarks of their respective owners. This is a non-commercial fan project. It uses original artwork
> and free fonts, and it contains no text or images from the books or shows.

## Status

The 1701-D is playable (8 panels, 3 scenarios). Next: remove the dropped 1701-A/-E work and audit every
value against the manual (Phase 5). See the plan.
